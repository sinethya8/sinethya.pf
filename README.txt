HOW TO USE
1. Unzip, double-click index.html to open it.
2. Replace assets/images/hero.jpg with a new main photo (same name).
3. Replace assets/documents/cv.pdf with a new CV (same name).
4. Put the official MAS logo at assets/images/mas-logo.png.
5. Edit the DATA block at the top of the <script> in index.html to change skills, projects, certificates, education.
